# 🎮 Number Hunt – Time Attack (Python Mini Game)

A fast-paced terminal-based Python game where players must quickly find and enter the target number from a randomly generated grid before time runs out. Difficulty increases as your score grows — testing both speed and focus.

Perfect as a beginner-friendly Python mini project and GitHub streak project.

---

## 🚀 Features

- 🧠 Reflex & focus based gameplay  
- ⏱️ Time-attack mechanic  
- 📈 Increasing difficulty levels  
- 🔢 Random number grid every round  
- ⭐ Score tracking  
- 💻 Runs in terminal (no external libraries required)

---

## 🛠️ Tech Stack

- Python 3
- Standard libraries only:
  - `random`
  - `time`
  - `os`

No third-party packages needed.
